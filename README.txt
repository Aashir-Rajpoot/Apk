APK banane ka tareeqa (mobile se bhi):
1. github.com par free account banayein, New repository banayein.
2. Is zip ko extract karke saari files (".github" folder samet) repository mein upload karein.
3. Repository mein "Actions" tab kholein -> "Build APK" run hone dein (3-5 min).
4. Run complete hone par neeche "Artifacts" se SprinkleApp-apk download karein, zip kholein, app-debug.apk install karein.
